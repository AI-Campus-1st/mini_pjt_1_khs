# 1차 미니 프로젝트

# 경기도 청년층 인구와 생활 밀착 업종 분포 분석

## 프로젝트 소개

청년층(20~39세)의 주요 여가·생활 활동과 관련된 
카페, 헬스장, PC방 업종을 대상으로 경기도 시군구별 
청년 인구와 업종 분포의 관계를 분석한 프로젝트입니다.

단순 업소 개수가 아닌 **청년 인구 1만 명당 업소 수(청년 업소밀도)**를 활용하여
지역별 공급 수준과 상권 특성을 비교 분석했습니다.


## 분석 목표

- 청년층 비율과 생활 밀착 업종 밀도의 관계 확인
- 업종별(카페·헬스장·PC방) 특성 비교
- 단순 업소 수와 정규화 지표 비교
- 청년 인구 구조가 유사한 지역 간 상권 차이 분석
